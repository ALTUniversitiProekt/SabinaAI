# 🚀 Sabina AI — Эмоционалды Интеллект және Менторлық Платформасы

## 📌 Жобаның Мақсаты
**Sabina AI** — пайдаланушылардың өзара қарым-қатынасындағы психологиялық және эмоционалдық контексті талдауға арналған SaaS веб-платформасы. Жоба адамдар арасындағы диалогтардағы сөздің астарын, сұхбаттастың психотипін анықтап, жағдайға байланысты 3 түрлі тиімді әрекет сценарийін ұсынады.

---

## 🛠️ Технологиялық Стек
* **HTML5:** Семантикалық веб-құрылым.
* **CSS3 (Modern UI):** Flexbox, Grid Layout, Glassmorphism (әйнек эффектісі), CSS Variables және Glow Анимациялары.
* **JavaScript (ES6+):** Интерактивті чат логикасы, DOM-компоненттерді динамикалық жаңарту және оқиғаларды өңдеу (Event Handling).
* **FontAwesome v6:** Векторлық иконкалар жүйесі.

---

## 🌟 Негізгі Функционалдары
1. **Эмоция мен Сөз Астарын Талдау:** Енгізілген хабарламаның негізгі мағынасын есептеу.
2. **Психотипті Анықтау:** Сұхбаттастың коммуникациялық модулін табу (ашық, тұйық, аналитик, т.б.).
3. **3 Түрлі Сценарий:** 
   - *Дипломатиялық* (жұмсақ/ресми)
   - *Әзіл-оспақ* (жеңіл қарым-қатынас)
   - *Тура / Нақты* (анық позиция)
4. **Дауыстық Енгізу (Voice-to-Text Mock):** Микрофон арқылы хабарлама жіберу интерфейсі.
